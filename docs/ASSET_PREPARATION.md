# เตรียมโมเดลและข้อมูลนักแข่ง

## โมเดลรถ — ยังไม่เริ่ม Phase 2

1. เตรียมโมเดลรถจริงที่คุณมีสิทธิ์ใช้บนเว็บไซต์ พร้อมไฟล์ต้นฉบับและหลักฐานสิทธิ์
   ไม่ใช้รูปหรือ MP4 เปลี่ยนนามสกุลเป็น `.glb` และไม่สร้างชิ้นส่วนภายในที่ไม่มีอยู่จริง
2. เปิดตรวจใน Blender ว่ารูปทรง สี และ texture ครบ ไม่ใช่เพียงภาพ render ของรถ
3. ถ้าต้องการ exploded view ให้แยกชิ้นเป็น objects ที่มีชื่อชัดเจน เช่น
   `body`, `front_wing`, `rear_wing`, `wheel_fl`, `wheel_fr`, `wheel_rl`,
   `wheel_rr`, `suspension` เฉพาะชิ้นที่โมเดลมีจริง ไม่รวมทั้งหมดเป็น mesh เดียว
   โมเดลที่รวมเป็นชิ้นเดียวใช้แสดง/หมุนรถได้ แต่ยังไม่พร้อมแยกชิ้นส่วน
4. เก็บตำแหน่งประกอบรถให้ครบ กำหนด pivot ของล้อให้ตรงแกนล้อ และ scale ให้สอดคล้องกัน
   ส่งไฟล์ต้นฉบับก่อน export ไว้ด้วย เผื่อต้องปรับ hierarchy หรือวัสดุ
5. ใช้วัสดุ PBR ที่ export ได้ และ bake procedural texture เป็นรูปถ้าจำเป็น
   เป้าหมายเริ่มต้นของโปรเจกต์คือ texture 1K–2K และไฟล์ประมาณ 10–20 MB
   ตัวเลขนี้เป็นงบประมาณตั้งต้น ไม่ใช่ข้อบังคับหรือการรับประกันประสิทธิภาพ
6. Export ผ่าน **File → Export → glTF 2.0 → glTF Binary (.glb)**
   ให้ mesh และ textures อยู่ครบในไฟล์เดียว จากนั้นลอง import ไฟล์กลับมาตรวจ
7. วางไฟล์ที่ `public/models/f1-car.glb` แล้วแจ้งให้ตรวจไฟล์ก่อนอนุมัติ Phase 2

เมื่อได้รับไฟล์ จะตรวจจำนวน mesh/triangles, textures, material, hierarchy,
ขนาด และความพร้อมสำหรับแยกชิ้น โดยยังไม่เริ่ม WebGL จนได้รับอนุมัติ

อ้างอิงรูปแบบส่งออก: [Blender glTF manual](https://docs.blender.org/manual/en/dev/addons/scene_gltf2.html)

## ข้อมูลนักแข่ง — Ferrari Drivers

ตรวจจากเว็บไซต์ F1 วันที่ **28 สิงหาคม 2026**:

| นักแข่ง Ferrari | หมายเลข | ประเทศ | โปรไฟล์ทางการ |
| --- | --- | --- | --- |
| Charles Leclerc | 16 | Monaco | [F1 profile](https://www.formula1.com/en/drivers/charles-leclerc) |
| Lewis Hamilton | 44 | United Kingdom | [F1 profile](https://www.formula1.com/en/drivers/lewis-hamilton) |

[หน้า Ferrari ของ F1](https://www.formula1.com/en/teams/ferrari) ยืนยันรายชื่อทีม

แนวทางเนื้อหา: รูป portrait, ชื่อ, หมายเลข, ประเทศ, ทีม และประวัติย่อที่เขียนใหม่
แยกสถิติฤดูกาลออกจากประวัติ และแสดงวันที่อัปเดตพร้อมแหล่งข้อมูล
ยังไม่ควรแสดงคะแนนหรืออันดับว่าเป็นข้อมูลสดหากไม่มีระบบอัปเดต

สำหรับรูป ให้ส่งภาพที่อนุญาตใช้บนเว็บ พร้อมชื่อช่างภาพ/แหล่งที่มาและเงื่อนไขเครดิต
รูปที่เปิดดูได้บนเว็บไซต์ทางการไม่ได้ยืนยันสิทธิ์นำมาเผยแพร่ซ้ำ
แนะนำภาพแนวตั้งอย่างน้อยประมาณ 800×1000 px และชุดแข่งที่ตรงฤดูกาล
หากใช้ภาพเก่า ให้ระบุปีภาพอย่างชัดเจน ไม่สร้างภาพนักแข่งปลอมแทนภาพจริง

โฟลเดอร์เตรียมไว้: `public/images/drivers/`
ใช้ภาพที่ผู้ใช้ส่งมาแล้ว 4 ไฟล์: `lewis-png.png`, `lewis-shadow-png.png`,
`charles-png.png`, `charles-shadow-png.png` โดยไม่แก้หรือแทนที่ไฟล์ต้นฉบับ
ส่วน Drivers อยู่ที่ `/#drivers` และแก้ข้อมูลได้ใน `data/drivers.ts`
รองรับ hover, focus, tap และโหมดลดการเคลื่อนไหว ไม่มีสถิติคะแนนสด
ยังต้องยืนยันสิทธิ์เผยแพร่และเครดิตภาพก่อนเปิดเว็บไซต์สู่สาธารณะ
